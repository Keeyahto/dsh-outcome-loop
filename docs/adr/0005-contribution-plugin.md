# ADR-0005: 贡献模式 = 独立、默认未安装的本地数据集准备插件（设计记录）

**状态**：设计已接受，实现排期（阶段 7 第 6 项，先于 LLM Judge）｜**范围**：spec §5.3、§22

## 问题

贡献模式允许用户把（可选字段的）结果数据提供给训练方。它绝不能默认开启，绝不能降低个人模式功能，且必须满足 spec §5.3 的全部同意/披露/脱敏要求。

## 决策

贡献模式**不进入核心包默认 patch**。实现为一个独立消费者插件行 `outcome-loop-contribute`（同仓库、`cordis.patch.yml` 不含该行，用户手动添加），且必须满足：

1. **用户主动开启**：`contribute.enabled: true`（部署配置）且每次准备数据集都需显式命令；
2. **披露**：数据集目录内包含 consent manifest（接收方占位、用途说明、许可文本、保留期、补偿说明、撤回方式）；
3. **逐批预览**：`/outcome contribute preview <contract> --out <dir>` 生成批次清单 + 字段清单 + 敏感命中 + 内容 digest，不写任何文件；
4. **确定性脱敏与敏感项阻断**：复用 `redact.ts`；`secret` 类证据直接阻断（不进入数据集），`personal-data` 只允许聚合计数；
5. **只上传用户明确选择的字段**：字段白名单默认 = 导出 v1 最小集（不含消息正文/代码正文/绝对路径/credentials）；
6. **允许只上传汇总**：`--summary-only` 模式只写聚合统计（contract 数、criterion 通过率、token 分布），不写任何单条记录；
7. **同意记录**：manifest 记录 consent_version、时间戳、范围、撤回路径；数据集目录删除即撤回；
8. **训练方承担 token 成本**：本插件自身零模型调用；未来若引入重标注/反事实分支，成本归属在独立服务中记账，与核心无关；
9. **拒绝不降功能**：卸载贡献行后个人模式功能不变。

**网络边界**：MVP 的贡献准备只写用户指定本地目录（用户自行交付）；不做任何自动上传通道。未来若需要直传，必须是独立远程契约 + 显式配置 + 审计。

## 拒绝理由

- 在核心包内置"以后可能使用"的上传通道违反 §4.6/§22；
- 默认开启贡献违反 §5.3 的主动开启要求。

## 影响

- 隐私/token：默认零影响；贡献准备零模型调用；数据集最小化；
- 迁移：consent manifest 版本化；数据集格式 = 导出 v1 子集（`outcome-loop.contribution.v1`）；
- 测试：贡献模式回归套件（字段白名单、secret 阻断、摘要模式、同意记录、撤回=删除）；
- 回滚：删除插件行 + 删除数据集目录。

# ADR-0006: 企业策略只存在于部署配置，仓库内容永不授予策略

**状态**：已接受（2026-08-18，v0.1.0-beta.4 实现）｜**范围**：spec §5.2、§11、§24 决策 #10（保守默认）

## 问题

企业模式的强制策略（必需验收项、verifier 白名单、保留期）放在哪里？仓库内策略文件由不可信代码提交者控制，不能自动信任；签名机制超出 MVP。

## 候选

1. workspace 内策略文件（`.outcome-loop/policy.json`）；
2. 部署配置（`cordis.yml` / DSH user settings 的可信子集）；
3. 签名策略文件（需要密钥分发与验证基础设施）。

## 选择

**2**。`enterprise` 配置段（`requireCriteria` / `minCriteria` / `mustIncludeKinds` / `allowedVerifierIds`），仅在 `mode: 'enterprise'` 时生效，在 `createContract`/`reviseContract` 处纯函数强制（`enforceEnterprisePolicy`）。仓库/workspace 内容**永不**被读取为策略（与 active 验证的信任模型一致：项目配置不授予权限）。

## 拒绝理由

- 1：不可信内容自动获得强制力，违反 §11；
- 3：签名机制需要密钥轮换/吊销/审计，§24 #10 未决策前不做；未来可作为可选增强（策略文件 + 部署配置里的公钥指纹）。

## 影响

- 隐私/token：零模型成本；企业模式不记录更多原始内容；
- 迁移：策略字段全部可选、默认关闭，personal 模式完全不受影响；
- 测试：enterprise 强制在 create/revise 的拒绝路径；
- 回滚：`mode` 回到 `personal` 即全部解除。
